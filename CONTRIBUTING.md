# Contribuindo

1. Crie um ambiente virtual com Python 3.12 ou superior.
2. Instale `pip install -e .[dev]`.
3. Rode `ruff check .`, `mypy .` e `pytest` antes de abrir uma contribuição.
4. Toda nova fórmula deve ter teste determinístico e cadeia de proveniência.
5. Não inclua processos reais, dados pessoais, segredos ou tabelas oficiais sem fonte e vigência.

Pull requests devem explicar a regra jurídica, a fonte oficial, o período de validade e o impacto na memória de cálculo.
