# Uso

1. Converta documentos em `process_facts.json` preservando status, página e trecho.
2. Declare divisor, horas, pagamentos, avos e o `reflection_graph` no plano.
3. Rode `calculadora-trabalhista calculate ...`.
4. Revise a auditoria e a lista de dados ausentes antes de usar qualquer valor em uma peça.
