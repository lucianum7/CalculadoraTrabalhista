# Segurança e privacidade

Este projeto roda localmente e não envia processos para serviços externos. Não coloque dados pessoais ou processos reais no repositório.

Para reportar uma vulnerabilidade, abra um aviso privado no GitHub quando disponível ou descreva o problema sem incluir dados protegidos. Correções de segurança devem incluir teste de regressão e não devem expor documentos de clientes.

O motor falha explicitamente quando um parâmetro necessário está ausente; ele não transforma ausência em zero nem inventa fatos.
